不开游戏,先听一局

模拟一整局:主菜单 → 热身 → 回合开始 → 下包 → 拆包拿 MVP → 阵亡 → 比赛胜利,大约 1 分钟。

多个事件同时发生时

只播优先级最高的那个,低优先级的不会打断正在播放的高优先级音乐。主菜单、热身、回合开始和比赛结束总会切换。优先级在站点详情的“高级”里调。

剪辑台

拖动选出片段,试听满意后保存到曲库,或直接用在某个站点。

把音乐拖到这里,或点击导入
mp3 / ogg / wav / flac

    从左边选一首歌开始剪辑

    选好后可以拖动选区、循环试听、对齐节拍,再导出成一个新的音乐文件。

    吸附
    0.0 秒
    快捷键:空格 播放/停止,I O 把光标设为入点/出点,L 循环,滚轮缩放,Shift+滚轮平移

    AI 推荐

    分析每首歌的段落结构,按每个站点需要的感觉推荐从哪里切、切多长。先试听,满意再采用。

    社区

    分享你的音乐盒,或者导入别人的。分享的是“配方”:用哪首歌、每个站点从哪里切、切多长,不会上传任何音频。

    先连接一个社区服务器

    填入社区服务器的网址(搭建方法见 community 文件夹里的说明)。

    分享我的音乐盒

    把你现在音乐盒里配好的站点分享出去。别人导入时会用他们自己电脑上的同一首歌,程序会自动对齐时间。

      队友语音

      把你的麦克风和正在播放的音乐混在一起送进游戏语音,队友同时听到你说话和你的音乐。你自己耳机里听到的不变。

      实验性功能 这个功能还在测试阶段

      还没有在真实的 Windows + CS2 环境里充分验证,可能会遇到声音断续、没声音或设备认不出来等问题。遇到问题直接关掉它就行,不影响音乐盒的其他功能。

      需要你自己下载一个免费的虚拟声卡 VB-CABLE。本程序不附带、也不会替你安装它(它是 VB-Audio 公司的捐赠软件,装驱动需要管理员权限)。

      还差一步 没有检测到 VB-CABLE

      到官网下载 → 解压 → 右键 VBCABLE_Setup_x64.exe 选「以管理员身份运行」→ 点 Install → 重启电脑。装好后回到这里点「重新检测」。

      第一次使用

        哪些站点的音乐放给队友

        队友可以把你静音;一直往语音里放音乐,可能被举报「语音骚扰」导致暂时不能用语音。建议只在回合结束、MVP 这类时刻放,你说话时音乐会自动让路。

        设置

        连接 CS2

        程序会把 GSI 配置写进 CS2 的 cfg 文件夹;写入后需要重启一次 CS2。找不到时在这里填路径。

        关掉游戏自带音乐

        进游戏后在控制台输入 exec musicbox_mute。只把各类“音乐”音量设为 0,枪声和脚步不受影响;要恢复就到 设置 › 音频 › 音乐 把滑块调回来。

        计时

        “剩余 10 秒”是按回合开始和下包时间估算的。提示早了或晚了就在这里调。

        社区服务器

        社区用来分享和导入音乐盒。填入服务器网址,程序会先检查它是不是音乐盒社区。
